# Jinqiu Guo — Personal Academic Portfolio

Public website: https://chewkwok.github.io/

Research, creative practice, teaching, travel, and selected honours. Built with React and Vite; published with GitHub Pages.

## Update the website

Edit files in `src/` and commit to `main`. The Pages workflow installs the pinned dependencies, builds the website, and publishes it automatically.

```sh
pnpm install --frozen-lockfile
pnpm build
```

Media, papers, and the updated CV are stored in `public/`. The initial migration verifies every imported asset against a SHA-256 manifest and commits it into this repository. Once imported, deployment does not need the previous hosting provider.
